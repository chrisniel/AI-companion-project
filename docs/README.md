# AI Companion — Documentation Hub

This directory contains project documentation organized according to the strict numbered documentation hierarchy defined in [`AGENTS.md`](../AGENTS.md).

## Documentation Directory Structure

| Directory | Purpose | Status & Authority |
|-----------|---------|---------------------|
| [`00_Drafts/`](./00_Drafts/) | Raw ideas, scratchpads, and unreviewed notes. | Strictly non-authoritative; ignored by AI agents unless explicitly prompted. |
| [`01_Tracking/`](./01_Tracking/) | Sprint execution tracking and task archiving. Active tracking file: [`01_Tracking/task.md`](./01_Tracking/task.md). | **Canonical active execution state.** |
| [`02_Planning/`](./02_Planning/) | Feature-named implementation plans, acceptance criteria, and technical designs. Index: [`02_Planning/README.md`](./02_Planning/README.md). | Authoritative implementation specifications. |
| [`03_Walkthroughs/`](./03_Walkthroughs/) | Completed-work delivery walkthroughs and developer handovers. | Verification evidence and feature handovers. |
| [`04_Architecture/`](./04_Architecture/) | System contracts, API schemas, and core technical specifications. Master architecture: [`AI_COMPANION_MASTER_IMPLEMENTATION_PLAN.md`](./04_Architecture/AI_COMPANION_MASTER_IMPLEMENTATION_PLAN.md). | **Durable canonical technical architecture.** |
| [`05_Design/`](./05_Design/) | Product design documents, UI/UX guidelines, wireframes, and design tokens. | Authoritative design and experience specs. |
| [`06_Guides/`](./06_Guides/) | Contributor onboarding, local setup guides, environment configuration, and testing standards. | Operational & developer guides. |
| [`07_Archive/`](./07_Archive/) | Superseded drafts, historical audits, and deprecated documentation. | Historical reference only; not loaded into active context. |
| [`ProjectWorkflowStarterKit/`](./ProjectWorkflowStarterKit/) | Permanent reference templates and workflow kit assets. | Permanent reference (exempt from numbered layout). |
