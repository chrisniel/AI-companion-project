## 3. How the Logic Works

1. **Five Storage Roots & Relocation:** `get_canonical_paths()` derives `APP_INSTALL_ROOT`, `DATA_ROOT`, `LIBRARY_ROOT`, `CACHE_ROOT`, and `LOG_ROOT` purely from env overrides and `bootstrap.json` (ignoring global `bootstrap.json` `library_root` when `COMPANION_DATA_ROOT` env isolates a test run). `PUT /api/v1/system/storage/library-root` stops any idle router, verifies path safety, copies/verifies assets when requested, atomically updates `bootstrap.json`, emits `storageRevision` updates in Flutter so Runtime clears stale scans and updates its inbox path, and returns updated `StorageRootsResponse`.
2. **D6 Controlled Model Import, Dynamic Hardware Probe & Experimental Context:** User picks files directly via native Win32 **Add Model Files...** (`WindowsShellChannel` + Copy/Move staging) or drops `.gguf` (+ optional `mmproj-*.gguf`) into the auto-created `IMPORT_INBOX_DIR` (`<LIBRARY_ROOT>/imports/inbox`) and clicks **Scan Inbox** (`POST /models/import/scan`). `scan_import_inbox()` surfaces safety/engine warnings (blocking `.pt`/`.pth`/`.pkl`/`.ckpt`, explaining skipped `.safetensors`/`.onnx`/`.bin`), inspects GGUF headers (buffered `_skip_gguf_array` + `_GGUF_METADATA_CACHE`), and runs `assess_hardware_suitability()` + `compute_recommended_profiles_for_model()` against `probe_host_hardware()` Win32 GPU VRAM & RAM. On **Install Bundle** (`POST /models/import/install`), files stage into a unique `IMPORT_STAGING_DIR` subdir, verify SHA-256 + GGUF validity, move atomically (`os.replace`) into `<MODEL_LIBRARY_DIR>/<model_id>/` (respecting `transfer_mode`: `"move"` or `"copy"`), persist Schema v3 `models.json`, and promote idle `MockLLMProvider` in `auto` mode. Experimental `context_mode` (`"profile"`, `"16k"`, `"model_max"`) persists in `host_config.json` and resets active Core-managed router state on change.
3. **Windows Login Autostart & Flash-Free Tray Launch:** Toggling **Launch at Windows Login** (`PUT /system/autostart`) builds escaped Task Scheduler XML (`AICompanionAutostart`, `<UserId>` inside `<LogonTrigger>` and `<Principal id="Author">` from `_current_windows_user()`, `LeastPrivilege`, explicit `WorkingDirectory`, `--minimized-to-tray`) via `WindowsAutostartService`, with `CompanionClient._handleErrorResponse()` unwrapping nested `body['error']['message']`/`['code']` payloads. On Windows boot, `main.cpp` forwards `--minimized-to-tray` -> `FlutterWindow` skips first-frame `Show()` -> `main.dart` awaits `DesktopLifecycleCoordinator.initialize(showImmediately: false)` to minimize cleanly into the tray while `DesktopRuntimeCoordinator` resolves the backend executable up to `10` ancestor directories deep.

## 4. Key Concepts

- **`LIBRARY_ROOT` Isolation & Same-Volume Staging:** Placing `imports/inbox` and `imports/staging` inside `LIBRARY_ROOT` keeps large GGUF staging atomic (`os.replace`) even when `LIBRARY_ROOT` moves to `D:\` or `E:\`.
- **Dynamic Host Hardware Preflight & Safe Experimental Context:** `assess_hardware_suitability()` and `compute_recommended_profiles_for_model()` calibrate profile recommendations against probed PC VRAM/RAM without locking out manual model selection or opt-in experimental `>8K` (`16K` / `Model Max`) context overrides.
- **No Watchdog `/RI` Autostart:** Registering `LogonTrigger` cleanly without periodic restart intervals ensures `Exit Companion` stops the app intentionally as required by D2.

- **Preserved Invariants:** Zero directory creation on `resolve_*`/`get_canonical_paths()`, fail-closed `library_root` validation, strict GGUF key/generic-array bounds (`MAX_STRING_LENGTH = 1024`, `MAX_ARRAY_LENGTH = 64`), no background inbox polling watcher, offline standalone `SettingsStorageSection` (`client == null`) test invariants preserved.

## 7. Troubleshooting

- **Symptom:** Async chat streaming tests timed out (`2.0s`) during `build_model_list()`.
  - **Likely cause:** Calling `f.seek()` on every small string element in `tokenizer.ggml.tokens`/`merges` flushed Python's `BufferedReader` ~300k times per `.gguf` file.
  - **Resolution:** Sequential buffered reads (`<= 65536` bytes) in `_skip_gguf_array()` + size/mtime `_GGUF_METADATA_CACHE` (`>= 64 KB`) in `model_registry.py` cut `build_model_list()` latency from `2.803s` down to fast cached lookups and restored `test_attachment_binding.py` + `test_model_registry.py` to `84 passed in 18.63s`.
