## 3. How the Logic Works

1. **Native WASAPI & Hotkey Bridge:** `FlutterWindow` owns `WindowsAudioChannel`, registering `ai_companion/windows_audio` and routing `kWmAudioEvent` + `WM_HOTKEY` window messages safely on the UI STA thread while dedicated MTA audio threads capture 16 kHz PCM16 frames and mix/resample WAV/PCM output with generation-tagged buffer flushing. Tray right-click invokes `popUpContextMenu()` and preserves the mute check state across runtime heartbeats.
2. **Voice Control, Consumer Chat Cards & Shortcuts:** `DesktopVoiceController` coordinates hardware endpoint selection, WASAPI mic hot-swap, Settings **Test Mic**, isolated 60 Hz `micRmsListenable` UI meters, `HardwareKeyboard` shortcuts (`LogicalKeyboardKey` + `PhysicalKeyboardKey` matching, global `Ctrl+H` from any destination, `F8` mute backup), hard mute (`setMuted` pauses Live Voice capture **in-place** without killing WS & syncs tray/shell/chat pills), **Auto-Send** vs **Tap-to-Send** + **Send Now**, single-shot Composer dictation, grouped `Read Aloud` with playback-aware button reset, and Profile-switch cleanup. `ChatScreen` replaces developer receipt badges with auto-visible **7-day Weather Widget cards**, **Assistant Action cards**, friendly live tool status labels, and clean `Sources` strips.
3. **Backend Context, Tools & Real-Time Speech Synthesis:** Assistant orchestration compacts and prunes tool schemas (`select_relevant_tool_definitions` restricting casual banter to read-only `_CASUAL_SAFE_TOOL_NAMES`), guards auto-compaction against small 2-turn conversations and hallucinated digests, prevents transient seeking/movement facts from saving as permanent `is_core=True` memories, enforces strict word-boundary D9 provenance (`_TOOL_EXPLICIT_USER_PATTERNS` + filtering unoffered `<tool_call>` tags inside `_stream_guarded_sse_pass`), adds buffered Round-0 fallbacks (`_build_pre_armed_turn_fallbacks`) for explicit `web_search`/`weather_lookup`/`create_reminder`/`create_alarm` intents with negation and status-query guards, enforces `"Facts & Corrections First"` + `"Web Search Grounding"`, parses nested DuckDuckGo `<b>` tags and 7-day Open-Meteo forecasts accurately, and resolves naive/date-only scheduling ISO strings. `KokoroOnnxTtsProvider` preserves English clause punctuation for `espeak-ng` intonation, normalizes curly apostrophes/temperatures/decimals/`%`/arrows/slashes, chunks cleanly at `max_chars=420`, pads WAVs (`50ms/90ms/120ms`), and pairs with `VoiceSessionOrchestrator`'s `16`-frame/`40`-frame (`1.28s`) VAD endpointing and `0.65` dynamic speaker-echo guard.

## 4. Key Concepts

- **STA/MTA COM & Generation-Tagged Barge-In (`WindowsAudioChannel`):** Keeps Flutter's UI thread in `COINIT_APARTMENTTHREADED` while isolating WASAPI capture and render loops onto dedicated `COINIT_MULTITHREADED` worker threads, validating initial `StartCapture` endpoint activation synchronously, waking `RenderWorker` immediately on `render_flush_requested_` even when the FIFO is empty to cut buffered `<200ms` hardware tails, and dropping stale playback chunks by monotonic `playbackGeneration`.
- **D9 Explicit Provenance & `UNTRUSTED_CONTENT` Containment:** After `<untrusted_web_content>` enters the turn, only explicit word-boundary user intent patterns (`_TOOL_EXPLICIT_USER_PATTERNS`) classify as `EXPLICIT_USER`, while injected/unrequested mutating calls classify as `EXTERNAL_CONTENT` -> `DENY (EXTERNAL_CONTENT_FORBIDDEN)`, and unoffered `<tool_call>` tags outside `round_tools` are discarded at stream parse time.
- **Consumer Chat Surfaces (`chat_screen.dart`):** Converts machine-readable tool summaries cleanly on the client into a horizontally mouse/wheel-scrollable 7-day Weather Widget strip (`_WeatherForecastScrollStrip`) and consumer scheduling/memory confirmation cards without changing backend/OpenAPI contracts.

## 6. Safe Customization & Invariants

- **Do not weaken D9 provenance or schema pruning invariants:** Any new phrase added to `_TOOL_PROVENANCE_HINTS` or `_TOOL_EXPLICIT_USER_PATTERNS` must remain strictly word-boundary anchored and action-specific so common topics/substrings never promote `EXTERNAL_CONTENT` calls to `EXPLICIT_USER`.
- **Keep WASAPI threads STA/MTA separated and lock-free during COM calls:** Never call `audio_client->Stop()/Reset()` while holding `render_mutex_`, and always preserve `render_flush_requested_` wakeup on empty queues so `<50ms` barge-in works cleanly even on final audio tails.
- **Preserve Profile Isolation on Voice State:** `DesktopVoiceController.handleProfileEpochChanged()` must continue resetting `_playbackGeneration`, tearing down active WASAPI capture and WS sessions, and clearing cached transcripts/settings synchronously on every Profile switch.

## 7. Troubleshooting

- **`No matching location found` on follow-up weather queries:** Check `_WEATHER_TEMPORAL_NOISE_RE` / `_WEATHER_NON_LOCATION_TOKENS` in `orchestrator.py` and confirm `Profile.quiet_hours_timezone` is a valid `Region/City` IANA string (`Asia/Manila`).
- **`python_dependency_lock.py verify` mismatch on Python 3.13 local `.venv`:** Expected locally when Windows developer `.venv` uses Python 3.13 while CI targets `Windows x64 / CPython 3.11.9` (`requirements.lock` enforces CPython 3.11 wheels cleanly in GitHub Actions `Contract Verification`).
- **`StartCapture` returns `AUDIO_CAPTURE_ERROR`:** Confirm a Windows microphone endpoint is enabled in OS Sound Settings or select an explicit capture device ID under `Settings -> Voice & Audio`.
