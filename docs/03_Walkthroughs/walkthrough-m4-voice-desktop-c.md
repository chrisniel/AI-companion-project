## 3. How the Logic Works

1. **Native WASAPI & Hotkey Bridge:** `FlutterWindow` owns `WindowsAudioChannel`, registering `ai_companion/windows_audio` and routing `kWmAudioEvent` + `WM_HOTKEY` window messages safely on the UI STA thread while dedicated MTA audio threads capture 16 kHz PCM16 frames and mix/resample WAV/PCM output with generation-tagged buffer flushing. Tray right-click invokes `popUpContextMenu()` and preserves the mute check state across runtime heartbeats.
2. **Voice Control, Turn-Taking & Shortcuts:** `DesktopVoiceController` coordinates hardware endpoint selection, WASAPI mic hot-swap, Settings **Test Mic**, isolated 60 Hz `micRmsListenable` UI meters, `HardwareKeyboard` shortcuts (`LogicalKeyboardKey` + `PhysicalKeyboardKey` matching, global `Ctrl+H` from any destination, `F8` mute backup), hard mute (`setMuted` pauses Live Voice capture **in-place** without killing WS & syncs tray/shell/chat pills), **Auto-Send** vs **Tap-to-Send** + **Send Now**, single-shot Composer dictation, grouped `Read Aloud` with playback-aware button reset, and Profile-switch cleanup.
3. **Backend Context, Tools & Real-Time Speech Synthesis:** Assistant orchestration compacts tool schemas, weights UTF-8 tokens, skips empty failed/cancelled rows and denied action receipts, allows multi-round `Risk 0` web/weather lookups while protecting `EXTERNAL_CONTENT` writes, parses nested DuckDuckGo `<b>` tags and `"City"` weather names accurately, injects local timezone + warm persona context, and resolves naive/date-only scheduling ISO strings. `KokoroOnnxTtsProvider` preserves English clause punctuation for `espeak-ng` intonation, normalizes `/`, chunks cleanly at `max_chars=420`, pads WAVs (`50ms/90ms/120ms`), and pairs with `VoiceSessionOrchestrator`'s `16`-frame/`40`-frame (`1.28s`) VAD endpointing and `0.65` dynamic speaker-echo guard.
