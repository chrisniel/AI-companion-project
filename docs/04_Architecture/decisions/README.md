# Architecture Decisions (ADR)

This directory records accepted product decisions (ADR-0001 through ADR-0012).

## Numbering and Status Semantics
- **ADR-0001:** Repository/LFS topology (Not a D-numbered product decision).
- **ADR-0002 through ADR-0012:** Corresponds to decisions D1 through D11.
- **Status:** All records here are "Accepted".

## D-Number Mapping
- **D1 -> ADR-0002**: V1 Release Boundary
- **D2 -> ADR-0003**: Windows Host Model
- **D3 -> ADR-0004**: Android Application Identity
- **D4 -> ADR-0005**: Profile & Device Credential Boundary
- **D5 -> ADR-0006**: Remote Access Trust Boundary
- **D6 -> ADR-0007**: Controlled Model Acquisition
- **D7 -> ADR-0008**: Profile-First Memory Ownership
- **D8 -> ADR-0009**: Single Primary User Baseline
- **D9 -> ADR-0010**: Typed Tool Security Policy
- **D10 -> ADR-0011**: Scheduling and Notification Semantics
- **D11 -> ADR-0012**: Persona and State Separation

## Normative Authority
- ADRs record accepted decisions, context, consequences, and change control.
- **Focused domain specifications remain the primary normative domain owners.** ADRs do not become competing domain owners.
- Superseding an accepted ADR requires explicit human approval and a superseding decision record.
