For readable same-bitness processes (`static_assert(sizeof(void*) == 8)`), dynamically resolves `NtQueryInformationProcess` (`ntdll.dll`), reads documented x64 `PEB` (`+0x20` `ProcessParameters`) and `RTL_USER_PROCESS_PARAMETERS::CommandLine` (`+0x70` `UNICODE_STRING`: `Length`, `Buffer`) via byte-count-checked `ReadProcessMemory` (`Length` even, `0 <= Length <= 16384`), and reads `GetProcessTimes` creation `FILETIME` formatted as UTC ISO-8601.

## 6. Risks, Dependencies, Assumptions & Safeguards

- **Win32 PEB Read Boundary:** Elevated or WoW64 external processes cannot have `CommandLine` read by a standard-user 64-bit Desktop process. **Mitigation:** Fail closed on any `PROCESS_VM_READ` denial / WoW64 mismatch by returning `needsFallback: true` so `WindowsRuntimeProcessSupervisor` invokes the proven PowerShell `Get-CimInstance` query.
- **Fast-Path Schema Check Soundness:** Skipping `ScriptDirectory` when at head must never bypass corruption checks or miss pending migrations. **Mitigation:** Retain missing-`alembic.ini` error, `st_size == 0`, and full `inspect_legacy_candidate()` (`integrity_check` + `alembic_version`) on every startup, falling back to full Alembic on any deviation or branched `migrations/versions/` chain.
- **Active Turn & Lock Contention:** Holding `LlamaCppProvider._lock` up to 75s during `load_model()` would stall `ResourceGovernor` if `apply_resource_policy()` awaited the lock blindly. **Mitigation:** Check `_lock.locked()`, transitional load/unload states, and `has_active_generation` without blocking; return `deferred_model_load` / `deferred_active_turn` immediately and apply cleanly on the next monitor tick.
- **Required Permissions:** Phase 1 planning files only (`plan-m5-resource-governance-a.md` and `task-feature-m5-resource-governance-a.md`) committed/pushed to `feature/m5-resource-governance-a`; Phase 2 code edits and PR creation require Human Owner Phase 1 Plan Approval.
- **Genuine Stop Conditions:** Material scope expansion into Batch B/C features or Rust Stage 2 edits, unapproved SQLite schema migration, security/D10 invariant conflict, or unresolvable test failures.
